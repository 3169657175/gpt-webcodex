# 网页 MCP 助手 0.5.4

内置 Coding Tools MCP Runtime：0.5.2；MCP Schema 保持 v8。

## 可见进度

- ChatGPT 上方新增独立的本地任务进度栏，每 3 秒读取一次实际任务状态；运行时间每秒更新。
- 展示当前步骤、下一步、运行测试或构建等状态；失败和等待用户处理时显示实际原因。
- ChatGPT 正在生成但尚未调用本地工具时，显示“ChatGPT 正在生成回复”，不把模型内部规划伪装成本地进度。
- 长任务请求模型文字汇报的间隔从 90 秒缩短为 30 秒；是否在聊天消息中及时出现仍由 ChatGPT 决定。桌面进度栏不依赖模型主动汇报。
- 修正“等待模型”阶段被顶栏误显示为“执行中”的问题。

## Git Worktree 预检

- 创建隔离 Worktree 前先检查未跟踪文件数量。超过既有 500 文件快照上限时，立即返回实际数量和处理建议，不再先运行 Git 暂存、创建 Worktree，最后以超时报错。
- 不自动切换到直接修改模式；用户可清理或忽略生成文件，或明确选择直接工作区流程。

## 工作流与诊断准确性

- 模型指令明确要求：用户指定当前工作区直接修改时，`agent_workflow` 必须传 `isolation=off`；失败后继续同一任务，应先恢复任务状态。
- 退出码为 0 的命令，即使输出中提到“command not found”，也不再被误标为 `EXECUTABLE_NOT_FOUND`。
- 安装包不再包含内置 MCP 源码树中开发/测试生成的 `__pycache__` 和 `.pyc` 缓存。

## Python 项目环境识别

- 自动测试规划会读取项目 `requires-python`，优先探测项目 `.venv` / `venv`；项目要求更高 Python 版本而只有内置 MCP Python 时，明确标记测试和构建不可用。
- 识别 `test/` 与 `tests/` 两种测试目录，并提示需要 `localhost` 服务的集成测试必须按项目约定单独启动。
- 不把任意项目的 `sqlalchemy`、`curl_cffi`、`tiktoken`、`pytest` 安装进助手便携运行时；项目依赖属于项目自己的环境。
