# v0.4.4 网页 MCP 助手

v0.4.4 修复了盘符根目录工作区导致的部署失败误报，并新增最近工作区清理能力。内置 Coding Tools MCP Runtime 保持 v0.4.9 不变。

## 修复

- **盘符根目录工作区归一化**：将整个盘符（如 `D:\`）设为工作区时，设置里会存成盘符相对路径 `D:.`（Node `path.normalize('D:')` → `D:.`），而 Python Runtime 侧 `Path('D:.').resolve()` 返回绝对根 `D:\`，导致 `/__control/health` 的 workspace 校验永远失败，部署空转约 35 秒后误报“可能仍连接到旧进程”。现在 `normalizeWorkspacePath` 将 `D:` / `D:` / `D:\` / `D:\.` / `D:\..` 统一归一为 `D:\`，旧设置中的 `D:.` 在下一次加载时自动规范化。
- **健康检查失败报错更准确**：启动阶段身份健康检查超时的报错改为如实列举可能原因（健康接口未就绪、工作区/鉴权/源码指纹不一致、旧进程占用端口），不再单独归咎“旧进程”。

## 新增

- **最近工作区清理**：聊天页工作区下拉框旁新增“清理”按钮，弹出面板支持逐条 ✕ 移除与“清理全部记录（保留当前）”。当前工作区被标记为不可删除，后端经 `config.normalize` 兜底回填，即使误传目标也不会被真正删除。

- Windows 安装包：`web-mcp-assistant-setup-0.4.4.exe`
