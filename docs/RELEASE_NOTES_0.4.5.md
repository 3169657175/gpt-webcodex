# v0.4.5 网页 MCP 助手

v0.4.5 带来了多项面向开发者日常编码体验的重大增强，包括会话上下文监控、任务实时输出控制台、一键打开工作区、任务完成音效通知及修改文件变更树。内置 Coding Tools MCP Runtime 保持 v0.4.9 不变。

## 新增功能

- **上下文容量统计与监控系统**：
  - 客户端顶部栏新增「上下文 0k」实时容量药丸徽章（绿色畅通 / 黄色适中 / 橙红高负荷预警）；
  - 悬浮卡片展示累计 Token 估算、网络传输体积（KB）、工具调用次数、最大单次输出及健康提示，支持一键清零重新统计。
- **任务实时输出控制台（Terminal Drawer）**：
  - 顶部任务栏内置「控制台」按钮，展开暗黑专业终端界面（Cascadia Code 等宽字体）；
  - 实时流式输出 stdout / stderr 输出流与当前执行命令详情，支持自动滚动、一键复制、清屏与**一键强行终止当前命令**；
  - 保持顶栏 112px 黄金高度不变，抽屉以浮层展示，不破坏 ChatGPT 网页视图。
- **一键打开工作区工具**：
  - 工作区状态卡片新增「📂 资源管理器」和「💻 VS Code」快捷按钮，支持一键呼出本地编辑器或系统文件管理器。
- **任务完成托盘通知与完成音效提示**：
  - 任务在后台完成或需要确认时，Windows 右下角弹出 Toast 通知并支持点击聚焦激活窗口；
  - Web Audio 纯代码合成双音节清脆完成提示音（D5 ➜ A5 正弦渐变），无外部音频依赖，100% 离线可用。
- **本地修改文件实时变更树**：
  - 任务产生文件修改时自动亮起 `📝 N 文件` 徽标；
  - 控制台抽屉支持「实时日志」与「修改文件」自由切换，点击单项即可在本地资源管理器中高亮定位文件。

## 版本信息

- 网页 MCP 助手：**0.4.5**
- Coding Tools MCP Runtime：**0.4.9**（未变更，Schema 契约校验一致）
- Windows 安装包：`web-mcp-assistant-setup-0.4.5.exe`
