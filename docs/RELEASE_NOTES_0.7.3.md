# 网页 MCP 助手 v0.7.3

本次版本主要对管理中心、工作区窗口和配置隐私做了一轮收尾优化，重点解决日常使用中比较影响体验的窗口切换、状态误判和界面信息暴露问题。

## 更新内容

- 修复“设置与诊断”和“工作区中心”在 **Alt + Tab** 切换后被主界面覆盖、看起来像自动退出的问题。两个窗口现在正确归属于主助手，只有主动关闭或返回 ChatGPT 时才会隐藏。
- 继续整理管理中心 UI：统一侧边导航、压缩运行状态区域、重新组织设置分组，让首页和设置页更紧凑、更容易读。
- 修正 ChatGPT MCP 的就绪状态判断，`waiting-first-attachment` 不再被误显示成黄色异常；基础链路正常时会按真实状态显示“就绪”。
- 优化启动链路状态展示，未执行阶段不再像“熄灭/失败”，完成、进行中、待执行和异常状态区分更清楚。
- 配置教程中的 **Tunnel ID 改为默认脱敏显示**，不再自动把完整 ID 填入教程输入框；完整配置只保留在明确的连接设置区域。
- 清理历史版本构建产物和旧发布说明，工作目录只保留最近两个安装包与对应说明。
