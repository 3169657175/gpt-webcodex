# 网页 MCP 助手 v0.9.1

这是 0.9 系列的稳定性收口版本，重点修复状态反馈、桌面提醒、长期上下文冲突和 React 状态一致性问题。

## 主要变化

### 运行状态与活动详情
- 活动详情隐藏无意义的等待模型心跳和空输出，只保留真正有用的命令、阶段和异常信息。
- 最近事件做去噪、去重和中文化，减少 `running / completed / exited` 等原始英文状态直接暴露。
- 设置页和关于区域的版本号改为读取 Electron 实际版本，不再手工写死。

### 卡住提醒
- 修复心跳跨过 90 秒阈值后 `stalled` 已判定但桌面通知可能不弹出的状态比较问题。
- 现在从正常运行进入疑似卡住时只提醒一次，后续轮询不会重复弹窗。
- `waiting_model` 继续保持静默，不把正常等待 ChatGPT 误判成卡死。

### 长期上下文 V3
- 修复候选与候选之间同主题不同内容时，新事实可能被旧候选吞掉的问题。
- 冲突候选现在会独立保存，并携带旧内容与新内容供管理界面对比后再决定覆盖或另存。
- 新增 V3 Legacy 清理：明显的超长阶段式一次性任务 Prompt 会被安全归档，不再污染启动上下文；显式记忆和模型正式总结不自动清理。
- 清理采用归档而不是永久删除，可随时回看历史记录。

### React / TypeScript 状态统一
- 管理中心 React 层不再自行解析 `task.status` / `lifecycle_state`。
- `app.js` 统一发布经过 `AssistantState` 归一化后的中文状态、语义色调和诊断信息。
- `renderer-ui` 去除宽泛 `Record<string, any>` 状态定义，改为明确的 TypeScript 类型。
