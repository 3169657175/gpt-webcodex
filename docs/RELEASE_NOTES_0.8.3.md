# 网页 MCP 助手 v0.8.3

v0.8.3 重点完成两项真实使用体验修复：运行详情改为原生悬浮窗口，以及本地记忆从“聊天片段收藏”重构为长期用户画像。

## 原生运行详情浮窗

- 鼠标悬停聊天顶部主进度条时，使用独立的 Electron 子窗口展示运行详情，不再依赖会被 ChatGPT WebContents 覆盖的 DOM 弹层。
- 浮窗覆盖在助手自己的 ChatGPT 窗口上方，但不会修改 `toolbarHeight`、不会调整 ChatGPT View bounds，也不会把聊天页面向下挤压。
- 展示当前状态、阶段、真实耗时、最近活动、心跳、进程、等待原因、下一步、Task / Run / Operation ID、最近结果、命令、输出和事件时间线。
- 支持悬停保持、延迟关闭、点击固定、取消固定和 Esc/关闭按钮。
- 本地命令正在运行时，详情中的“当前阶段”优先显示“正在执行本地命令”，不会再被旧的 `Waiting for model` 覆盖。

## 本地记忆 v2：长期画像

- 自动记忆默认启用；旧版本因默认配置为 `off` 而静默停止采集的安装会一次性迁移回自动模式，之后用户明确选择关闭仍会被尊重。
- 自动记忆只提炼稳定、可复用的信息：身份与长期背景、技术兴趣、常做项目、工作与协作方式、沟通/产品偏好、常用环境，以及明确的项目长期规则。
- 一次性问题、临时 Bug、普通任务请求、短期目标、闲聊、凭据和敏感个人信息不再进入长期画像。
- 同类信息写入固定画像槽位并合并更新，不再“每轮聊天新增一条”，避免记忆库无限膨胀。
- 首次运行 v2 会提炼旧 `auto_chat` 中仍有价值的事实，并把旧聊天片段归档；历史数据保留在本机，但不再污染启动上下文。
- “置顶”语义改为“核心画像”：只有全局核心偏好/工作方式可以设为核心画像；项目记忆继续限定在对应工作区。

## 兼容性

- MCP Tool Schema 保持 v12 / 9 tools，无需重新创建插件。
- 旧 Memory Markdown / SQLite 数据结构继续兼容，迁移只归档旧自动条目并生成新的摘要画像。
