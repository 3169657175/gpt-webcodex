# 网页 MCP 助手 0.7.0 发布说明

0.7.0 是一次围绕长任务可观察性、网页兼容性和原生 UI 稳定性的迭代。

## 主要变化

- 移除嵌入 ChatGPT 页面中的工具调用折叠器及其 CSS/MutationObserver 注入，避免跟随 ChatGPT 页面更新反复失效。
- 新增网页生成活动监测：持续观察停止生成控件和 DOM 活动；45 秒没有新页面活动时显示停滞提示，并提供“停止生成”。
- 识别动态 import、ChunkLoadError 等页面资源加载失败，提供手动刷新入口；不会因为网页层错误重启本地 Runtime。
- 任务事件流收到状态后立即刷新主聊天页，3 秒轮询继续作为断线兜底，并用并发闸门避免重复请求。
- `exec_command` 在进程无输出时仍每 5 秒更新任务心跳，避免静默命令被误判成卡死。
- 下载完成的附件增加“打开附件”动作，直接打开当前工作区中的本地文件。
- 设置中心删除已经没有意义的“折叠已调用工具”选项，避免保存旧配置再次触发网页注入。

## 兼容性与边界

- ChatGPT 模型内部思考过程仍由网页端控制，MCP 不能读取或伪造 token 级思考进度；助手现在会明确区分“网页生成中”“本地任务执行中”“等待模型”和“页面停滞”。
- 页面刷新是用户主动操作，不会自动刷新当前对话，也不会无条件重启健康的 MCP Runtime。
